# I/O & Manifest Contract (`tools/` ↔ `server/` ↔ `web/workers/io_worker.js`)

## HTTP Server Requirements (`server/serve_local.py`)
- `/` serves static files from `web/`.
- `/data/<path>` serves local files from `--data` (default `local-data/`), rejecting path traversal (`..`).
- Every response includes:
  - `Cross-Origin-Opener-Policy: same-origin`
  - `Cross-Origin-Embedder-Policy: require-corp`
  - `Cross-Origin-Resource-Policy: same-origin`
  - `Accept-Ranges: bytes`
- `GET /data/...` with `Range: bytes=<start>-<end>` returns `206 Partial Content` with exact `Content-Range` and `Content-Length`.

## `data-manifest.json`
Generated by `cargo run -p playgta6-tools -- --game <dir> --out local-data/data-manifest.json`:

```json
{
  "abi_version": 1,
  "file_count": 2,
  "total_bytes": 1048576,
  "files": [
    {"path": "levels.rpf", "size": 1048000},
    {"path": "MicrosoftGame.Config", "size": 576}
  ]
}
```

## `bootset.json` (Optional Prefetch List)
Array of hot initial byte ranges prefetched by `io_worker.js` during boot:

```json
[
  {"path": "levels.rpf", "offset": 0, "length": 65536}
]
```
